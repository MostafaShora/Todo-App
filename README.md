# 🚀 TaskFlow

A modern, feature-rich Task Management Application built with Angular 22 that showcases scalable frontend architecture, Angular Signals, reusable standalone components, and a polished user experience.

TaskFlow helps users organize daily tasks through an intuitive interface with advanced filtering, sorting, drag-and-drop reordering, localization, and persistent storage.

---

## ✨ Features

### 📋 Task Management

- Create, edit, and delete tasks
- Mark tasks as completed or pending
- Set priorities (Low, Medium, High)
- Assign categories
- Due date management
- Overdue task detection

### 🔍 Smart Organization

- Search by task title
- Filter by status, category, and priority
- Sort by:
  - Manual order
  - Newest
  - Oldest
  - Name
  - Priority
- Drag & Drop task reordering

### 🎨 User Experience

- Responsive design
- Dark / Light mode
- Toast notifications
- Confirmation dialogs
- Smooth animations
- Empty-state UI
- Modern dashboard layout

### 🌍 Internationalization

- English & Arabic
- RTL / LTR support
- Language preference persistence

### 💾 Persistence

- LocalStorage for:
  - Tasks
  - Theme
  - Language
